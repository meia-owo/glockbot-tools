## 目的
天井の G×第2カウンタとは別に、ホールで **初当たり〜連チャンの履歴**を親指操作で残せるようにする。  
「いま連チャン中のセット」と「終わったセット（何連したか／スルーか）」をはっきり分ける。

## スコープ（0.2）
- **まず南国SPECIALタブのみ**（スルー＝飛翔に繋がらなかった初当たり、という定義が南国向け）
- 他2機種は 0.2 ではログUIを出さない（共通データ形だけ用意してよいが、タブUIは南国のみ）
- 既存の状態ボード・示唆早見・天井モードは維持。ログは **状態ボード／入力の下、示唆早見の上または直下**（親指で届く）
- 単一HTML・CDNなし・localStorageのみ・外部送信なし
- ダッシュボード掲載は不要（趣味枠）

## 用語（アプリ内の言い方）
| 用語 | 意味 |
|---|---|
| **初当たりセット** | 通常からの1回の初当たりを起点にした一連。ボーナスを時系列で積む単位 |
| **進行中セット** | まだ終了していないセット。画面上で「いま」と強調 |
| **終了セット** | やめた／通常に戻したセット。連チャン数とスルー判定が確定 |
| **連チャン数** | そのセット内のボーナス回数（初当たりボーナスを1連目と数える） |
| **BIG / REG** | ボーナス種別。必ず区別して記録 |
| **スルー** | **セット単位**。その初当たりセットが **飛翔に繋がらずに終了**したらスルー +1。日次の別カウンタは作らない |

## やること
1. 進行中が無いとき: **「初当たりを記録」**  
   - 必須: 初当たりG（デフォルト＝いまの状態ボードのGを流用、編集可）  
   - 任意: その時点のスイカCOUNT（ボード値を流用可）  
   - 1発目ボーナス種別: BIG / REG（必須）  
   - これで進行中セットが始まり、連目=1
2. 進行中があるとき: **「ボーナス追加」**（BIG / REG）→ 連目+1  
3. 進行中の終了:  
   - **「飛翔に繋がった」** → スルーではない。セット終了。任意でメモ1行  
   - **「スルーで終了」** → スルー +1（セットにフラグ）。セット終了  
   - **「やめた（判定保留）」** → 終了だがスルー未確定（`through: unknown`）。後から直せるなら尚可  
4. 一覧:  
   - 上段: 進行中セット（太枠・「いま」）。連チャン中であることが一目で分かる  
   - 下段: 今日の終了セット（新しい順）。各行に 初当G / 連数 / BIG・REG内訳 or 時系列短縮 / スルー有無  
5. 集計バー（南国タブ内・コンパクト）:  
   - 今日のスルー回数（終了セットで through=true の件数）  
   - 今日の初当たりセット数  
   - （任意）最大連チャン  
6. 既存 deep の「スルー回数（任意）」は **セット由来の今日スルーに置き換え or 同期**。二重入力させない  
7. 機種別 localStorage。キー案: `smaslo-ceiling-memo:v2:nangoku-sp:sets`（v1 天井値は壊さない）  
8. 当該機種のセット全クリア（確認ダイアログ）

## データ形（案）
```js
{
  dayKey: "2026-09-25", // ローカル日付。日付跨ぎで「今日」集計を切る
  activeId: "set_...", // or null
  sets: [
    {
      id: "set_...",
      startedAt: ISO,
      endedAt: ISO|null,
      firstHitG: 512,
      firstHitSuika: 4, // optional
      bonuses: [
        { n: 1, type: "BIG"|"REG", at: ISO },
        { n: 2, type: "REG", at: ISO }
      ],
      // 終了時
      linkedHisho: true|false|null, // true=飛翔に繋がった / false=スルー / null=保留
      note: ""
    }
  ]
}
```
表示用: `renchanCount = bonuses.length`  
スルー集計: `sets.filter(s => s.endedAt && s.linkedHisho === false).length`

## UI詳細
- 進行中カード例: `いま 初当 512G / 3連目 / BIG→REG→BIG`  
- ボタンは大きく: `[+ BIG] [+ REG]` `[飛翔で終了] [スルーで終了]`  
- 終了セットは折りたたみ可（初期は直近3件オープン、他は閉じ）  
- スクロール抑制: ログ全体を高めのカード1枚に収め、長い履歴は内部スクロールでも可（メイン操作はボード優先）  
- 「設定○」「この台はスルー確定」などの断定コピー禁止。ラベルはユーザー操作の記録
