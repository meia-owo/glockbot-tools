# 安川ロボット（YASKAWA）制御データ差分チェックツール

ステータス: 実装依頼中 → GlockBOTツールビルダー
優先度: 高（ユーザーから渡された未完成仕様の最終形）
依頼元: GlockBOTマスター（こっこsan代理）

## ゴール
変更前後のYASKAWA制御データを比較する差分チェックツールを、**HTML単一ファイル**で完成させる。

## 技術制約
- HTML + CSS + JavaScript のみ（単一ファイル）
- 外部依存はCDN可
- Excel出力は SheetJS（`xlsx.full.min.js`）をCDNから利用
- 社内ローカル利用想定：ネットが切れるとSheetJS読込失敗しうる点はコメントで明記可。まずはCDN版で完成。

## UI
- 左右2エリア：Before（変更前）/ After（変更後）
- ドラッグ&ドロップでファイル読込
- フォルダDnD対応（`webkitGetAsEntry`）
- クリックでのファイル選択も対応
- 各サイド上限 **300ファイル**。超過時は警告表示
- 対応拡張子：`.JBI` `/` `.DAT` `/` `.CSV` `/` `.TXT` `/` `.INI` `/` `.PRM`（大文字小文字両対応）
- ファイル読込エンコード：**Shift_JIS**

## 比較オプション
- 比較モード：行単位 / 空白行を無視 / 大小文字を無視（組み合わせ可否はUIで明確に。最低限ラジオorチェックで切替可能に）
- 対象フィルタ：すべて / JBIのみ / DATのみ / CSVのみ

## 差分アルゴリズム
- LCS（最長共通部分列）ベースの行単位差分
- 隣接する del+add は **mod（変更）** としてまとめる
- ステータス：`changed` / `clean` / `added` / `deleted`

## 結果表示
- 親行（ファイル名）＋子行（差分行）の階層
- 親行クリックで展開／折りたたみ
- **差分なしでも**「差分検出なし（N行比較済み）」を必ず表示（証跡要件）
- 変更・追加・削除・差分なしを色分け

## Excel出力（3シート）
1. **サマリー**：ファイル一覧、ステータス、差分行数
2. **差分詳細**：変更種別・行番号・変更前後。差分なしファイルも「差分検出なし」行を必ず出力
3. **全文対照（エビデンス）**：Before/After全行を横並び、差分行に★マーク

## 出力ファイル名
`YASKAWA_差分チェック_（タイムスタンプ）.xlsx`

## ファイル照合ルール（仕様に明示が薄いのでマスター決定）
- 相対パス（フォルダ構造込み）のファイル名で Before/After をマッチ
- Afterのみ → added、Beforeのみ → deleted、両方あり → 行差分で changed/clean
- 同名衝突時は警告し、先頭を採用（またはパス単位で一意化）

## 完了条件
1. `/workspace/apps/yaskawa-diff-check/index.html` に単一HTMLを保存
2. 手元で動作確認できるよう、簡単な使い方メモを同フォルダに `README.md` で添付
3. マスター（id経由）へ完了報告：できたこと／未達／既知の制限

## やらないこと
- 会社ネットワーク制限の回避
- 外部サーバへのデータ送信
- 多ファイル分割・ビルドツール必須化
