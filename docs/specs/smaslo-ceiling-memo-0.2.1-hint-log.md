## 目的
0.2.0 の初当たりセットに、**その区間で見た示唆**を残せるようにする。  
ボーナスとボーナスのあいだ、およびセット終了〜次の初当たりまでの「通常待ち」も含む。照合用の記録であり、モード・設定の断定はしない。

## 前提
- 0.2.0 が Pages 上で動いていること（進行中セット・ボーナス追加・飛翔／スルー終了）
- 既存の示唆早見 `hints[]`（when / means / strength / section / group）を **選択肢の正**にする
- 南国SPECIALタブのみ。他機種は出さない
- 自動検知なし・カメラ／音声なし・CDNなし

## 区間（segment）の切り方
タイムラインはセットのライフサイクルに沿う。

| 区間IDのイメージ | いつ開く | いつ閉じる |
|---|---|---|
| `pre-bonus-1` または `after-start` | 初当たり記録直後（1連目ボーナス消化〜次アクション前） | 次のボーナス追加、またはセット終了 |
| `between-n-(n+1)` | n連目ボーナスを記録した直後 | (n+1)連目ボーナス追加、またはセット終了 |
| `post-set`（通常待ち） | セットを終了した直後 | **次の初当たりを記録したとき**（その瞬間に閉じる） |

ルール:
1. **ボーナスを1回記録するたびに、直前の区間を閉じ、新しい空区間を開く**
2. セット終了時も同様に区間を閉じ、続けて **通常待ち区間**を1つ開く（次初当まで示唆を拾える）
3. 次の初当たり開始で通常待ちを閉じ、新しいセットの最初の区間へ
4. 進行中セットが無いときの示唆は、直近の `post-set`（通常待ち）へ入る。通常待ちが無ければ「待ち区間を開始」相当で作ってよい

表示ラベル例: `1連目中` / `1→2連のあいだ` / `セット後〜次初当`

## データ形（0.2.0 を拡張）
各 set に:

```js
hintEvents: [
  {
    id: "he_...",
    segmentKey: "between-1-2", // or "post-set"
    segmentLabel: "1→2連のあいだ",
    when: "さざなみ前兆 赤", // MACHINES hints[].when と一致推奨
    means: "約85%で通常B以上寄り", // 選択時にスナップショットしてよい
    strength: "濃厚",
    section: "mode"|"setting",
    group: "途中"|...,
    note: "", // 任意・短文
    at: ISO
  }
]
```

セットに属さない通常待ちだけ残る場合は、軽量な `waitingHints: { segment..., events[] }` を同 LS ルートに置いてもよい（実装判断。ただし UI 上は「次初当までの示唆」と分かる）。

LS: 0.2.0 の `smaslo-ceiling-memo:v2:nangoku-sp:sets` を破壊的に捨てない。マイグレーションで `hintEvents: []` を足す。

## UI
配置: 進行中セットカードの内側（または直下）。親指で「示唆を残す」が届くこと。示唆早見の照合表は残し、そこから「この行をログへ」でも可（どちらか一方必須、両方あると尚可）。

1. **「示唆を残す」** → 既存 hints を group 見出し付きリスト（終了時／途中／ボーナス中／設定）で選択  
2. 選択で現在開いている区間に1件追加（時刻自動）  
3. 任意でメモ1行  
4. 進行中カード内に、今区間の直近数件を小さく表示  
5. 終了セット詳細を開くと、区間ごとの示唆一覧  
6. 通常待ち中も同じ「示唆を残す」が使える

やらない表示:
- 「だから通常B」「設定6確定」などのアプリ断定
- 示唆からの自動モード推定バー

## やること／やらないこと
やる:
- 南国のみ hintEvents 記録・区間自動開閉（ボーナス記録・セット終了・次初当に連動）
- 既存 hints タップ選択が主入力
- 版 `GlockBOT 0.2.1`、selfcheck、Pages、スクショ（区間に示唆が付いた進行中／終了詳細）

やらない:
- 他機種、自由記述だけのカオス入力を主にする（メモは任意の副）
- 示唆早見データの大幅追加依頼（足りない when は別チケット）
- 0.2.0 のスルー定義変更
