# スマスロ「ヤバチバ」天井・状態把握メモ

版: **GlockBOT 0.1.0**（趣味枠／Pages可）

ホールでその場で使える **天井・状態把握メモ**。内部モード／ゾーンは主UIに出さず、**現在G × チェリー回数**の紐付けで先着天井を一目で見る。

## 開き方

1. `index.html` をブラウザで開く（`file://` 可・CDNなし・外部通信なし）
2. または GitHub Pages 等に静的配置（趣味枠のため掲載は任意）

パス: `apps/yabachiba-memo/`

## 操作

| 操作 | 内容 |
|---|---|
| Gスライダー | 大きくドラッグ（0〜1200表示／内部は9999まで可） |
| ±1 / ±10 | 細かい調整 |
| 数値入力 | 直接入力も可 |
| チェリー +1/−1 | 主入力（大きいボタン） |
| 細いチェリースライダー | 補助 |
| 設定変更トグル | ON でチェリー天井 40→**30** |
| リセット | Gのみ／チェリーのみ／両方 |
| 副次パネル | 初期閉じ。ベル集中・花笠・虹7・設定表・立ち回りメモ |
| セッション | localStorage 自動保存／リセット／JSON 書出・読込 |

## 先着ラベル（リード論理）

- `remainingG = max(0, 999 - g)`
- `remainingCherry = max(0, cherryCap - cherry)`（cap は 40 または 30）
- 進捗比 `g/999` と `cherry/cap` を比較し、高い方が天井に近い
- **近い**の定義: 残り ≤ キャップの 10% **または** ≤50G / ≤5 チェリー
- 比がほぼ同じ（\|差\| &lt; 0.03）かつ両方近い → 「ほぼ同時」
- 比がほぼ同じ／どちらも近くない（進捗 &lt; 0.55）→ 「どちらも余裕」
- それ以外 → 「G先」または「チェリー先」（先着側を太枠・「先」・暖色系）

## 内蔵定数（MACHINE）

- 機種: Lヤバチバ（型式 LヤバチバZM）／ネット・製造オーゼキ／チバリヨ系
- 天井: 999G+α **または** チェリー40（設定変更時30）先着
- 初当り: 全設定共通 1/398（表示メモのみ・判別に使わない）
- ベル集中突入率（約）: 1=1/7163 / 2=1/6509 / 3=— / 4=1/3643 / 5=1/2906 / 6=1/1767
- 機械割: 1=97.1% / 2=98.3% / 3=— / 4=102.9% / 5=105.1% / 6=110.1%

※ HTML 内 `MACHINE` オブジェクトを編集すれば更新できる。

## 出典・注意

数値は導入直後の解析サイト掲載（独自調べ含む）を寄せた参考値。

- メーカー公式の全数値公表ではない
- 今後の解析で修正されうる
- 本アプリは **非公式** の個人用メモ
- **煽り・「勝てる」断定はしない**
- 個人収支・店舗名はクラウドに送らない（localStorage のみ）
- ギャンブル依存に注意。のめり込みを感じたら休憩・相談を

主要出典は導入時の解説メモ（2026-09-25 共有）および一般公開の解析まとめを参照。URL は変動しうるため、利用時に最新の解析記事で再確認すること。

## 制限

- 天井「+α」の詳細は機種仕様に依存し、本メモでは 999G を基準表示
- ベル集中・花笠・虹7は任意入力の副次のみ（判別エンジンではない）
- 解析値の正しさは保証しない。判断は人が行う
