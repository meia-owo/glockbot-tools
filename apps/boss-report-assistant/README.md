# 上司報告 攻略ツール

**GlockBOT 0.2.0**

メモ／会議テキストから「報告の4要素チェック → 報告文 → パワポ構成＋台本」を整える単一HTMLツールです。

## 使い方

1. `index.html` をブラウザで開く（ネットワーク不要）
2. メモを貼る／4要素フォームを埋める
3. 「情報を確認して報告文を作る」→ 不足があれば質問 → 報告文 → パワポ構成
4. 報告文全文／スライド台本／撮影リストをコピー

## モード

| モード | 説明 |
|---|---|
| **オフライン（推奨・デフォルト）** | ヒューリスティック判定＋テンプレート組み立て。API不要。社内利用はこちら |
| **AI（APIキー）** | 自分の Anthropic API キーで `CHECK` / `GENERATE` / `SLIDES` プロンプトを呼び出し |

### AIモードの注意

- 入力内容が Anthropic に送信されます（有効化前に確認ダイアログあり）
- APIキーは任意で localStorage に保存可能（ハードコードなし）。保存キーは画面から消去可能
- **ブラウザ CORS**: `file://` や許可されていないオリジンからは Anthropic API がブロックされることがあります。失敗時はオフラインモードを使ってください
- モデル既定値: `claude-sonnet-4-6`

## 成果物

- `index.html` — アプリ本体（HTML+CSS+JS、CDNなし）
- `README.md` — 本ファイル
- `_selfcheck/` — オフライン生成の Node 自己検査

## 自己検査

```bash
node _selfcheck/run.js
```
