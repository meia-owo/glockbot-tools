# メーカー別見積単価データベース化ツール v2

版: GlockBOT 0.1.0

古エクセルメモ帳を置き換える、検索・フィルタ・編集可能な見積単価DB（単一HTML + localStorage）。

## 使い方

1. **Edge / Chrome** で `index.html` を開く（ダブルクリックまたはドラッグ＆ドロップ）
2. 初回起動時に **利用者名** を入力（更新履歴の `updated_by` / `changed_by` に使用。設定タブで変更可）
3. 「CSV / JSON取込み」から同梱の `sample-import.csv` を取り込む
4. **未正規化キュー** で標準作業名を一括付与（例）
   - `ロボット据付け調整` / `据付工事一式` / `据付け調整工事` / `据付調整` → **`据付調整`**
   - `配線接続工事` / `配線接続` / `ケーブル配線工事` → **`配線接続`**
5. 一覧・比較タブでフィルタ／メーカー比較／乖離判定を確認
6. 設定・バックアップから JSON 全量バックアップを取得（共有・容量退避用）

### 乖離デモのヒント

サンプルCSVは仕様の2行＋追加8行です。取込み直後は未正規化のため乖離は「判定不可」。上記のように標準作業名を揃えると、グループが3件以上になり中央値ベースの乖離率が表示されます。山田重工の据付は新旧2時点があり、メーカー比較セルに `(旧: ¥… YYYY-MM)` が出ます。

## 主な機能

- 一覧・比較（フィルタ、単価／見積日ソート、ページング100件、メーカー間突き合わせ）
- 乖離判定（単価／原単位モード、中央値、閾値スライダー、グループ3件未満は判定不可）
- CRUD（新規・編集・論理削除／復元・フィールド単位履歴）
- 未正規化キュー（メーカー×原文名の一括正規化＋エイリアス登録）
- エイリアス辞書（部分一致サジェスト）
- CSV/JSONインポート（バリデーション、重複スキップ／上書き／別追加、見積日のファイル単位補完、スキップ行CSV）
- Excel出力（SheetJS）／JSONバックアップ・復元（全置換 or マージ）

## 制限・注意

| 項目 | 内容 |
|---|---|
| 保存先 | ブラウザーの **localStorage**（端末・プロファイル依存） |
| 容量 | 目安 **約5MB**。逼迫時は JSON バックアップへ退避 |
| Excel | **SheetJS CDN**（`xlsx-0.20.3`）必須。オフライン／CDNブロック時は Excel 出力不可 |
| 外部送信 | 見積データはサーバへ送りません（Excel用スクリプト読込のみ） |
| PDF抽出 | **対象外**（コパイロット等でCSV化した結果を取り込む前提） |
| インポート出典 | CSVの `source_type` は `見積書PDF` / `古エクセル` のみ（手動入力は画面CRUD） |

## ファイル

- `index.html` — 本体（CSS/JSインライン）
- `sample-import.csv` — 取込みサンプル
- `_selfcheck/` — 中央値・乖離・CSV検証などの Node テスト
