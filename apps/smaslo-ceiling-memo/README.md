## 操作

| 操作 | 内容 |
|---|---|
| 機種タブ | 上部固定。切替でキャップ・ラベル・示唆が差し替わる |
| 天井モード | ヘッダ付近のセレクト／設定変更トグル／通常系40トグル |
| G ±1/±10 | 大きめボタン（スライダーなし・0.3.2） |
| **G直入＋反映**（0.3） | 大きめ数値入力（inputmode=numeric）＋「反映」。Enterでも反映 |
| 第2 +1/−1 | 大きいボタン（スライダーなし・0.3.2） |
| **1つ戻す**（0.3） | 直前の G／第2カウンタ変更を最大10段 undo（機種別） |
| **初当たりセット**（南国 0.2／ヤバチバ 0.3） | ボード＋入力の下、示唆早見の上。進行中と終了を分けて記録。チバリヨ2は非表示 |
| **示唆を残す**（同上） | 進行中カード／通常待ちから hints 選択で区間付きログ。終了セットはタップで区間別一覧 |
| 示唆早見 | 状態ボード直下の折りたたみ（初期閉じ可）。見たもの→意味・強度ラベル。「この行をログへ」（セット有効機種） |
| 副次メモ | さらに奥。設定表・立ち回り。南国の今日スルーはセット由来（読取専用） |
| 当該機種リセット | カウンタをクリア。セット有効機種は続けてセット／示唆ログも消すか確認 |
| 全機種JSON | 書出／読込（天井状態＋ v2 sets を `sets` フィールドに含める） |

## 初当たりセット／連チャン／スルー（南国 0.2／ヤバチバ 0.3）

| 用語 | 意味 |
|---|---|
| **初当たりセット** | 通常からの1回の初当たりを起点にした一連。ボーナスを時系列で積む単位 |
| **進行中セット** | まだ終了していないセット。画面上で「いま」と強調 |
| **終了セット** | やめた／通常に戻したセット。連チャン数とスルー判定が確定 |
| **連チャン数** | そのセット内のボーナス回数（初当たりボーナスを **1連目** と数える） |
| **BIG / REG** | ボーナス種別。必ず区別して記録 |
| **スルー（南国）** | **セット単位**。その初当たりセットが **飛翔に繋がらずに終了**したらスルー +1 |
| **スルー（ヤバチバ）** | **セット単位・自動**。セット終了時に連チャン数===1（初当のみ）ならスルー。連>=2 は「連あり」。飛翔概念なし・機種内部の断定ではない |

### 操作フロー

1. 進行中なし → 「初当たりを記録」: 初当G（既定＝ボードG）・任意の第2COUNT・1発目 BIG/REG → 進行中開始（連目=1）
2. 進行中あり → `[+ BIG] [+ REG]` でボーナス追加
3. 終了:
   - **南国**: `[飛翔に繋がった]`／`[スルーで終了]`／`[やめた（判定保留）]`
   - **ヤバチバ**: `[セット終了]`（連1→スルー／連2+→連あり）／`[やめた（判定保留）]`
4. 集計バー: 今日スルー数／今日セット数／最大連
5. 「セット全クリア」は確認ダイアログ付き（機種名入り）

チバリヨ2タブにはセットログUIを出さない。

### 示唆ログ（南国・ヤバチバ）

1. 進行中カード（または通常待ちカード）の「示唆を残す」→ 当該機種 `hints[]` を選択
2. 現在開いている区間に1件追加（任意メモ可）。断定UIなし
3. カード直下に今区間の直近数件を小さく表示
4. 終了セット行をタップすると区間ラベルごとの示唆一覧
5. 示唆早見カードにも「この行をログへ」


## localStorage キー

```
smaslo-ceiling-memo:v1:<machineId>         # 機種別天井状態（0.1系・壊さない）
smaslo-ceiling-memo:v1:activeTab           # 最後に開いたタブ
smaslo-ceiling-memo:v2:<machineId>:sets    # 機種別 初当たりセット／示唆ログ（0.3）
smaslo-ceiling-memo:v2:nangoku-sp:sets     # 南国（0.2 からキー不変）
smaslo-ceiling-memo:v2:yabachiba:sets      # ヤバチバ（0.3）
```

`machineId` ∈ `yabachiba` / `chibariyo2` / `nangoku-sp`（セット有効は南国・ヤバチバのみ）

### セットデータ形（要約）

```js
{
  dayKey: "YYYY-MM-DD",
  activeId: "set_..." | null,
  openSegment: { segmentKey, segmentLabel, setId|null } | null,
  waitingHints: null | {
    segmentKey: "post-set",
    segmentLabel: "セット後〜次初当",
    endedSetId, events: hintEvent[], openedAt
  },
  sets: [{
    id, startedAt, endedAt: null|ISO,
    firstHitG, firstHitSuika?,
    bonuses: [{ n, type: "BIG"|"REG", at }],
    linkedHisho: true|false|null,
    note: "",
    hintEvents: [{
      id, segmentKey, segmentLabel,
      when, means, strength, section, group, note, at
    }]
  }]
}
```

- `renchanCount = bonuses.length`
- 今日スルー = 今日に属する終了セットで `linkedHisho === false` の件数
- 日付跨ぎ: `dayKey` を今日に更新し履歴は保持。「今日」表示は `startedAt`／`endedAt` のローカル日付でフィルタ
- **区間**: 初当開始 → `after-start`（1連目中）／ボーナス追加ごとに `between-n-(n+1)`／セット終了 → `waitingHints`（post-set）／次初当で waiting を前セットへアーカイブ
- 旧セット（hintEvents なし）は読込時に `[]` へマイグレーション（破壊しない）

## 先着ラベル（リード論理）

- `remG = max(0, gCap - g)` / `remC2 = max(0, c2Cap - c2)`
- 進捗比を比較。高い方が天井に近い
- **近い**: 残り ≤ キャップの 10% **または** ≤50G／チェリー系 ≤5／スイカ系 ≤1
- 比がほぼ同じ（\|差\| &lt; 0.03）かつ両方近い → 「ほぼ同時」
- どちらも近くない（進捗 &lt; 0.55）→ 「どちらも余裕」
- それ以外 → 「G先」／「チェリー先」／「スイカ先」

## 示唆早見

- `hints[] = { when, means, strength, section, group? }`
- strength: `濃厚` / `示唆` / `弱` / `調査中`
- 南国の PUSH「可!／良!／極み!」は **設定示唆**セクション（モード示唆と分離）
- **自動判定しない**。「設定○です」断定UIなし

## 制限

- 天井「+α」の詳細は機種仕様に依存し、表示は各 gCap 基準
- チバリヨ2／南国の設定表はプレースホルダ

- 日付跨ぎの「今日」は端末ローカル日付依存
- Undo は G／第2カウンタのみ（セット操作は対象外）
