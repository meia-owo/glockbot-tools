# スマスロ天井・状態把握メモ（3機種タブ）

版: **GlockBOT 0.1.0**（趣味枠／Pages可）

ホールでその場で使える **天井・状態把握メモ**。機種タブ切替で定数・示唆早見・天井モードを差し替える。  
正の仕様: `/workspace/specs/smaslo-ceiling-memo-0.1.md`  
旧単機 `apps/yabachiba-memo/` は本アプリへ統合（誘導ページのみ残置）。

## 開き方

1. `index.html` をブラウザで開く（`file://` 可・**CDNなし・外部通信なし**）
2. または GitHub Pages 等に静的配置（趣味枠・掲載は任意）

パス: `apps/smaslo-ceiling-memo/`

## 機種タブ

| タブ | id | 主軸 | G天井 | 第2カウンタ |
|---|---|---|---|---|
| ヤバチバ | `yabachiba` | G × チェリー | 999 | 40（設定変更時30） |
| チバリヨ2 | `chibariyo2` | G × チェリー | 通常999／リセット350／600 | 45（任意トグルで通常系40） |
| 南国SPECIAL | `nangoku-sp` | G × スイカ | 通常799／短縮500 | 0–9（3/5/7マーク・9濃厚） |

切替後も **機種別 localStorage** で値が残る。

## 操作

| 操作 | 内容 |
|---|---|
| 機種タブ | 上部固定。切替でキャップ・ラベル・示唆が差し替わる |
| 天井モード | ヘッダ付近のセレクト／設定変更トグル／通常系40トグル |
| Gスライダー | 大ドラッグ ＋ ±1/±10 ＋ 数値直入 |
| 第2 +1/−1 | 大きいボタン主（細いスライダー可） |
| 示唆早見 | 状態ボード直下の折りたたみ（初期閉じ可）。見たもの→意味・強度ラベル |
| 副次メモ | さらに奥。設定表・立ち回り・任意カウンタ |
| 当該機種リセット | アクティブ機種のカウンタのみクリア |
| 全機種JSON | 書出／読込（3機種まとめて） |

## localStorage キー

```
smaslo-ceiling-memo:v1:<machineId>   # 機種別状態
smaslo-ceiling-memo:v1:activeTab     # 最後に開いたタブ
```

`machineId` ∈ `yabachiba` / `chibariyo2` / `nangoku-sp`

## 先着ラベル（リード論理）

- `remG = max(0, gCap - g)` / `remC2 = max(0, c2Cap - c2)`
- 進捗比を比較。高い方が天井に近い
- **近い**: 残り ≤ キャップの 10% **または** ≤50G／チェリー系 ≤5／スイカ系 ≤1
- 比がほぼ同じ（\|差\| &lt; 0.03）かつ両方近い → 「ほぼ同時」
- どちらも近くない（進捗 &lt; 0.55）→ 「どちらも余裕」
- それ以外 → 「G先」／「チェリー先」／「スイカ先」

## 示唆早見

- `hints[] = { when, means, strength, section }`
- strength: `濃厚` / `示唆` / `弱` / `調査中`
- 南国の PUSH「可!／良!／極み!」は **設定示唆**セクション（モード示唆と分離）
- **自動判定しない**。「設定○です」断定UIなし

## 機種別出典・注意

数値は解析サイト掲載（独自調べ含む）の寄せ集め。メーカー公式の全数値公表ではない。今後修正されうる。

### ヤバチバ（LヤバチバZM／ネット・製造オーゼキ）

- 天井 999G+α または チェリー40（設定変更後30）
- ベル集中突入率・機械割は旧単機メモと同系の参考表
- 花笠／バックランプ／トップランプ／虹7は照合用の短いカード

### チバリヨ2（Lチバリヨ2ZB／ネット・製造オーゼキ）

- 通常999／リセット350 or 600、チェリー45（通常系40説はトグル）
- 花笠ボイス・トップランプ・単チェ等は次回モード寄り示唆
- 脚注: ボーナス後32Gやめ目安
- 設定表はプレースホルダ（最新解析で要更新）
- 2プラスは別機種（本タブ対象外）

### 南国SPECIAL（L南国育ちSPM1／アムテックス・平和）

- 通常799／短縮500、スイカ9濃厚・3/5/7マーク
- バタフライ終了フラッシュ色＝モード寄り／PUSHボイス＝設定示唆
- 脚注: ときめき後やめ／赤虹続行寄り
- 設定表・狙い目はプレースホルダ（自己判断）
