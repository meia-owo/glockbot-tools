# Teams文字起こし「熱量・曖昧度可視化」MVP

版: GlockBOT 0.1.0

Teams の文字起こし（WEBVTT / プレーンテキスト）をブラウザだけで読み込み、発言単位の **熱量** と **曖昧度** を辞書ルールで 0–100 スコアリングし、サーモグラフィー風に色分けする単一 HTML ツールです。

データはサーバへ送りません。CDN・外部 API なし（`file://` で動作）。

## 開き方

1. `index.html` をダブルクリック（またはブラウザへドラッグ）
2. 「サンプル読込」で動作確認、または Teams Recap から落とした `.vtt` をドロップ
3. 「解析」→ テーブル／サマリー／エクスポート

同梱の `sample.vtt` はディスク上の参照用です。画面の「サンプル読込」は **HTML 埋め込みテキスト** を使うため、ネットワーク不要で `file://` でも動きます。

## 入力形式

| 形式 | 例 |
|------|-----|
| Teams WEBVTT | `00:00:01.000 --> 00:00:05.000` + `<v 田中>本文</v>` |
| プレーン | `田中: 本文` / `田中：本文` / `[00:01:10] 田中: 本文` |
| 貼り付け | 上記をテキストエリアへ |

話者が `Speaker 1` 等の場合は「話者名の修正」で実名に置換できます。

## スコア（辞書ルール）

- **曖昧度**: 日本語ヘッジ（思う／かもしれない／一応／検討／様子を見る 等）の密度＋疑問・言いさし
- **熱量**: 決断・義務・強調語（必ず／絶対／やります／期限／担当します 等）＋感嘆符＋発話長の軽い補正
- セルにマウスオーバーで **根拠語**（マッチした辞書語）を表示

正規化は `1 - exp(-raw / k)` を 0–100 に丸めた近似です。

> **スコアは辞書ルールの近似です。人事評価用途禁止。**  
> 皮肉・文脈・本音の読み取りは対象外です。

## 画面機能

- ドロップゾーン／ファイル選択／貼り付け／解析
- 色分けテーブル（#・時刻・話者・本文・熱量・曖昧度）
- 話者チェック＋熱量／曖昧度バンド（低／中／高）と min–max
- サマリー: 話者別平均、熱量トップ、曖昧発言トップ
- **HTMLエクスポート**: 印刷用スタンドアロン HTML（色付き）
- **議事録下書き** コピー／DL: 決定っぽい行／ToDoっぽい行／曖昧論点をヒューリスティック抽出（下書き）

## ファイル構成

```
teams-heat-ambiguity/
  index.html          … 本体（CSS/JS・サンプル埋め込み）
  sample.vtt          … Teams風サンプル（14 cues）
  README.md
  _selfcheck/
    core.js           … パース／スコア純関数（Node検証用）
    test.js
    grep-features.js
```

`index.html` には `core.js` 相当をインラインで同梱しています（配布は単一ファイル優先）。ロジック変更時は `_selfcheck/core.js` を直し、HTML 側も同期してください。

## 自己チェック

```bash
node _selfcheck/test.js
node _selfcheck/grep-features.js
```

## 制限

- LLM／感情モデルなし。辞書ヒットの密度近似のみ
- Teams `.docx` 文字起こしは非対応（VTT/TXT）
- Graph API / Copilot 連携なし
- 議事録抽出はベストエフォート（必ず人が確認）
- 巨大トランスクリプトはブラウザメモリの制約を受けます
