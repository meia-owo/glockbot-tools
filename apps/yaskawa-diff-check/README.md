# YASKAWA 制御データ 差分チェック

版: GlockBOT 0.1.0

変更前／変更後の安川ロボット制御データ（JBI・DAT など）を、ブラウザだけで行単位比較する単一 HTML ツールです。  
データはサーバへ送信しません。

## 開き方

1. `index.html` をダブルクリックする（またはブラウザへドラッグ）
2. ローカルファイルとして開きます（`file://` で問題ありません）
3. Excel 出力にはインターネット経由の SheetJS CDN が必要です

> **CDN 注意**: SheetJS は  
> `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js`  
> から読み込みます。オフラインや CDN ブロック時は比較自体は動きますが、Excel 出力は失敗します。

## ファイルの読み込み

左右パネル（変更前 / 変更後）へ次のいずれかで読み込みます。

- **ドラッグ＆ドロップ**（ファイルまたはフォルダ）
- **ファイルを選択**（複数可）
- **フォルダを選択**（`webkitdirectory`）

フォルダ DnD は `webkitGetAsEntry` で再帰的に走査します。  
フォルダをドロップ／選択した場合、**最上位フォルダ名は照合キーから外し**、その中の相対パスで Before/After を突合します。

### 対応拡張子（大文字小文字不問）

`.JBI` `.DAT` `.CSV` `.TXT` `.INI` `.PRM`

### 文字コード

すべて **Shift_JIS** として読み込みます（`TextDecoder('shift-jis')` / `shift_jis` を試行）。

### 上限

各サイド **300 ファイル**まで。超過時は警告を出し、先頭 300 件のみ採用します（黙って捨てません）。

## 比較オプション

| 項目 | 意味 |
|------|------|
| 行単位 | 常時 ON。LCS ベースの行差分 |
| 空白行を無視 | 空白のみの行を比較対象から除外 |
| 大小文字を無視 | 比較キーを小文字化（表示テキストは原文） |
| 対象フィルタ | すべて / JBIのみ / DATのみ / CSVのみ |

チェックは組み合わせ可能です（例: 行単位 + 空白無視 + 大小無視）。

## 照合ルール

- Before / After は **相対パス（フォルダ構造込み）** でマッチ
- After のみ → **追加 (added)**
- Before のみ → **削除 (deleted)**
- 両方あり → 行差分 → **変更あり (changed)** または **差分なし (clean)**
- 同名パス衝突時は **警告し、先頭を採用**

## 結果表示

- 親行 = ファイル、子行 = 差分行（クリックで展開／折りたたみ）
- 差分なしファイルでも必ず子行に  
  `差分検出なし（N行比較済み）` を表示（証跡）
- 色分け: 変更あり / 追加 / 削除 / 差分なし
- 隣接する削除＋追加は **変更 (mod)** としてまとめます

## Excel 出力

ボタン「Excel出力」で次の 3 シートを書き出します。

1. **サマリー** … ファイル一覧・ステータス・差分行数
2. **差分詳細** … 変更種別・行番号・前後テキスト（差分なしも `差分検出なし` 行あり）
3. **全文対照** … Before/After 全行の横並び、差分行に ★

ファイル名例:

`YASKAWA_差分チェック_20260916_153045.xlsx`  
（ローカル日時 `YYYYMMDD_HHmmss`）

## デモ

画面の「デモデータを読み込む」で、変更／追加／削除／差分なしのサンプルを投入できます。

## 既知の制限

- 各サイド最大 300 ファイル
- 文字コードは Shift_JIS 固定（UTF-8 専用ファイルは文字化けする可能性）
- Excel 出力は SheetJS CDN 依存
- 対応拡張子以外はスキップ
- 画面上の差分行表示は 1 ファイルあたり先頭 250 行まで（全件は Excel に出力）
- 極端に巨大なファイル同士の比較はブラウザメモリ／時間の制約を受けます
- フォルダ DnD の挙動はブラウザ実装（特に Firefox のフォルダ DnD）に依存します。フォルダ選択ボタンも併用してください

## 自己チェック

```bash
node _selfcheck/test.js
```

LCS・隣接 del+add→mod・added/deleted・パス照合などのユニットテストを実行します。

