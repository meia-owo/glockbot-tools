# 川崎BXP 据付負荷スクリーニング — GlockBOT 0.3.0

単一HTMLの一次スクリーニングツール。ロボット動作ステップからベース反力・転倒モーメント・アンカー利用率を簡易推定し可視化する。**構造保証・適合判定ツールではない。**

## 版

**GlockBOT 0.3.0**

## 使い方

1. ブラウザで `index.html` を開く（ローカルファイルで可）
2. 左ペインで型式・ツール質量・架台高さ・アンカー有効/✕・ボルトプリセットを設定
3. 「動作」タブでプリセット選択、または CSV ペースト取込
4. **再計算** → 中央で再生、右ペインで出荷判定 KPI / M_floor(t) / 8本vs6本対照 / ボルト利用率を確認
5. **CSV出力**（UTF-8 BOM、`{型式}_据付負荷_{YYYYMMDD}.csv`）または **印刷レポート**

### 出荷判定（利用率 U）

判定指標: `U = T_op / Ta_long`（最悪ボルトの引張利用率）

| 判定 | U | T_op（Na=38.3kN時） | 対応（目安） |
|---|---|---|---|
| OK（出荷可） | U < 0.7 | < 約27 kN | その条件で出荷可（目安） |
| 要対策 | 0.7 ≤ U < 1.0 | 27〜38 kN | speed/Acc低減または補強 |
| NG | U ≥ 1.0 | ≥ 38.3 kN | 据付見直し必須 |

- 利用率0.7は疲労・繰返し（静的の約65%）を踏まえた**提案目安**
- 非常停止推定: `T_estop ≈ T_op × 1.8`（ABB比準用・**推定**）。`T_estop ≥ 57.5 kN` なら「非常停止NG（推定）」

### カタログ反力（メーカー公表・運転時）

| 型式 | 運転時 M | 運転時 T |
|---|---|---|
| BXP110S | 27 kN·m | 10 kN·m |
| BXP110L / 135X / 165L / 210L | 35 kN·m | 15 kN·m |

川崎は運転時の M,T のみ公表。非常停止・水平力は未公表。

### アンカー既定

- 長期許容引張 Na = **38.3 kN**（M20 接着系 AP-20 等、Fc=21、SS400）
- 短期許容引張 Na_short = **57.5 kN**
- 許容せん断 Qa は手入力

### ボルト配置プリセット

- **8本標準（川崎推定）**: (±195, ±170) と (±170, ±195) mm
- **6本（後部✕）**: 後部2本無効。松葉BKTは既定では効かない
- **松葉+2**: 「BKTを剛体として算入」トグルONのときのみ利用率に算入（OFF=安全側除外）

ボルト座標は仕様寸法からの**推定**。CADで要確認。

### CSV取込列

`step,J1,J2,J3,J4,J5,J6,speed,accel,weld_dwell`（カンマ/タブ両対応。ヘッダ行可）

### 対象型式

BXP110S / BXP110L / BXP135X / BXP165L / BXP210L

DH・質量配分は近似。M_tip/T_rot はメーカー公表・運転時。

## CDN / 社内ネットワーク注意

- 外部CDNは **Three.js r128（cdnjs 1 URLのみ）** を任意読込
- 社内プロキシ等で CDN がブロックされても、**Canvas2D 側面ビュー＋床平面図**が主表示のためスクリーニング自体は継続可能
- オフライン運用時は Three.js をローカルキャッシュ／同梱する運用を推奨（本版は単一HTML＋CDN参照）

```
https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
```
