# 川崎BXP 据付負荷スクリーニング — GlockBOT 0.1.0

単一HTMLの一次スクリーニングツール。ロボット動作ステップからベース反力・転倒モーメント・アンカー利用率を簡易推定し可視化する。**構造保証・適合判定ツールではない。**

## 版

**GlockBOT 0.1.0**

## 使い方

1. ブラウザで `index.html` を開く（ローカルファイルで可）
2. 左ペインで型式・ツール質量・架台高さ・アンカー有効/✕・松葉を設定
3. 「動作」タブでプリセット選択、または CSV ペースト取込
4. **再計算** → 中央で再生、右ペインで KPI / M_floor(t) / ボルト利用率を確認
5. **CSV出力**（UTF-8 BOM、`{型式}_据付負荷_{YYYYMMDD}.csv`）または **印刷レポート**

### CSV取込列

`step,J1,J2,J3,J4,J5,J6,speed,accel,weld_dwell`（カンマ/タブ両対応。ヘッダ行可）

### 対象型式

BXP110S / BXP110L / BXP135X / BXP165L / BXP210L

DH・質量配分・カタログ `M_tip` / `T_rot` は**近似・イラスト用プレースホルダ**（公式カタログ表からの転記でない場合あり）。画面にも注記あり。

## CDN / 社内ネットワーク注意

- 外部CDNは **Three.js r128（cdnjs 1 URLのみ）** を任意読込
- 社内プロキシ等で CDN がブロックされても、**Canvas2D 側面ビュー＋床平面図**が主表示のためスクリーニング自体は継続可能
- オフライン運用時は Three.js をローカルキャッシュ／同梱する運用を推奨（本版は単一HTML＋CDN参照）

```
https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
```

## 免責（フッター・印刷レポート常時表示）

> 本結果は簡易モデルによる推定値です。据付可否の最終判断は、川崎重工の据付・接続要領書および構造設計者による正式検討に基づいてください。

## 0.1.0 で実装したもの

- 3ペイン UI（ダークテーマ指定色）
- DH 順キネマ（6軸）＋関節スライダー／ステップ再生
- ステップ表・CSV取込・プリセット（旋回往復／上下ピック／フル速デモ）
- 集中質量→中央差分加速度→ Fx/Fy/Fz, M, T、DAF 既定 1.3
- 床換算 `M_floor = M + √(Fx²+Fy²)·h` 等
- 架台質量自動概算、アンカー弾性ボルト群（引張＋せん断）、利用率色分け
- M_floor(t) Canvas チャート＋カタログ線、KPI、CSV/印刷レポート
- 簡易ヒント（ルールベース）・カタログ最大モード
