# 業務効率化ワークベンチ（メールタスクエクスプローラー）

版: GlockBOT 0.2.0

メール本文からタスク候補を抽出し、カンバン風ボード／ICS／Markdown で扱う単一 HTML ツールです。  
あわせて Teams 議事録をコパイロット往復で構造化し、会議履歴・宿題を蓄積できます。

データはサーバへ送りません。外部 CDN・API キーなし（`file://` で動作）。コパイロット連携は **プロンプトコピー → 外部で実行 → 回答貼り戻し** のオフライン往復のみです。

## 開き方

1. `index.html` をダブルクリック（またはブラウザへドラッグ）
2. 上部タブで「📬 メール」または「📝 Teams議事録」を選択
3. 本文を貼り付け → 解析／プロンプトコピー → ボードへ／.ics 生成

## 継承した主な機能（原HTMLより）

### メールタブ
- 本文貼り付け → キーワード／日付ヒューリスティックでタスク候補抽出（`analyzeMail`）
- 候補の全選択／全解除 → ボードへ送出
- Markdown コピー、`.ics` エクスポート
- コパイロット往復: 整理用プロンプトコピー → 回答貼り戻し → `CALENDAR_START`〜`END` から `.ics` 生成

### Teams議事録タブ
- 議事録貼り付け → 解析用プロンプトコピー（外部コパイロットへ）
- 回答貼り戻し／クリップボード貼付 → プレビュー → 会議として登録
- 会議履歴ダッシュボード（決定・宿題・タイトル編集・個別プロンプト・PDF風印刷レポート）
- 累積会議の分析用コパイロットプロンプト、会議 JSON エクスポート

### 共通・ボード
- タスクボード（未対応／対応中／完了）・会議タイトルでのフィルタ
- タスク JSON の保存／読込
- ヘッダー統計（未対応・会議数・決定数）
- トースト通知

## 制限

- LLM／メールサーバ／Graph API 直結なし（ブラウザ内ヒューリスティック＋コパイロット往復）
- タスク抽出はキーワード近似。必ず人が確認すること
- ICS の日時解釈は日本語日付のベストエフォート
- 巨大な貼り付けはブラウザメモリの制約を受けます
- 免責文は本ツール対象外（N/A）。秘密情報・API キーは埋め込みません
